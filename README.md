## How to Use

1. Read the 6 steps on page 2 and pick one bedtime to keep every night.
2. Each evening, follow the wind-down steps in order: screens off, lights dimmed, quiet activity, then lights out.
3. Tick each bedtime step when it is done — bath or shower, pyjamas, teeth, bag packed, story or reading, lights out.
4. Each morning, write one line in the sleep log: bedtime, wake time, hours slept, and how the morning felt.
5. Follow the wake-up routine in order: alarm, up, water, stretch, dressed, breakfast, out the door.
6. Each week, write your sleep goals: a bedtime goal, a wake-up goal, one wind-down step to keep, and one thing to change.
7. Each evening, tick the screen-free checklist: phone out of the bedroom, TV off, devices put away, lights dimmed.
